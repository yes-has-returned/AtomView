# AtomView

## Disclaimer
This is currently prototype code for an ongoing project and is purely for testing. Any features or problems with the code are not final and will be changed.

## Overview
This program was made as a part of the NSW HSC Software Engineering Year 12 curriculum as a student major project. 

## Operation Directions
To install the program: 
1. Download the .zip file from [this repository](https://github.com/yes-has-returned/AtomView/releases/tag/testing)
2. Extract the contents of the folder

To run the program: 

3. From inside the extracted folder, open the folder AtomView, and then the file main.py
4. Run the file main.py using a built in python IDE or install vscode if this is not available
5. Go to the url localhost:5000/render
